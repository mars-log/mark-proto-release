# MARKPROTO 0.2.10

- 계정 메뉴 상단에 사진과 이름을 표시하고, 프로필에서 설정의 프로필 영역을 바로 엶.
- 사진 변경·삭제를 프로필 설정으로 옮기고 클라우드·동기화 옵션을 접힌 영역에 묶음. 로그아웃은 메뉴 마지막에 구분해 표시함.
- 문서 전환은 현재 위치의 반대 항목 하나만 표시함.
- 앱 잠금의 PIN 입력을 한 그룹으로 묶고 6자리 입력에 맞게 폭을 줄임. 저장·해제·즉시 잠금 버튼은 다른 설정 버튼과 같은 스타일을 사용함.
- 기존 문서 저장 위치·앱 식별자·업데이트 서명 키와 공용 로그인 서버 연결을 유지함. 실제 로그인 처리는 운영 MARKPROTO 서버의 mars-auth 설정을 사용함.

Windows는 설치 파일 또는 앱의 업데이트 기능으로 설치함. macOS는 해당 플랫폼 설치 파일이 공개된 경우 DMG의 앱을 응용 프로그램 폴더로 끌어다 놓아 대치함. Apple 인증서 서명·공증은 적용하지 않음.
