# MARKPROTO 0.2.7

- 기기별 6자리 PIN으로 앱 잠금을 설정할 수 있음. 앱 재시작·컴퓨터 잠금·15분 미사용 시 적용됨.
- PIN 오류가 반복되면 재시도 대기 시간이 늘어남. PIN을 잊으면 같은 계정으로 인증한 뒤 재설정할 수 있으며 노트는 보존됨.
- 테마에 잠금 화면 이미지를 선택적으로 포함할 수 있음. 이미지가 없거나 잘못되면 기본 화면으로 표시됨.
- 인증 서버 연결 실패로 로그인 정보를 지우지 않도록 보완함.
- 로컬 파일 복구가 늦게 끝나도 현재 선택한 파일을 유지함.

로그인 유지 기간 변경은 새 웹 서버와 세션 DB 마이그레이션 적용 후 새 로그인부터 적용됨. 이 Windows 설치 파일만으로 기존 서버의 12시간 세션이 바뀌지 않음.

Windows x64 릴리스임. macOS는 Mac에서 별도 빌드·검증·배포함. Windows OS 코드 서명과 앱 업데이트 서명은 별개임.
