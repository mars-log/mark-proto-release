# MARKPROTO 0.2.17

- 기본 테마에 파스텔 블루를 적용하고 설정에서 앱 아이콘을 선택할 수 있도록 함.
- 문서 이미지 읽기와 검색 미리보기에서 제한된 이미지 읽기 큐를 공통으로 사용함.
- 네이티브 창 소재에 맞는 배경 흐림 정책을 적용하고 기존 창 전환 가림을 유지함.

Windows x64와 macOS Apple Silicon 설치 파일을 제공함. Windows는 앱의 업데이트 확인 또는 NSIS 설치 파일로 업데이트할 수 있음. macOS는 DMG를 열고 앱을 응용 프로그램 폴더로 끌어다 놓아 대치함. Apple 코드 서명·공증은 적용하지 않음.
