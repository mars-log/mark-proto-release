# MARKPROTO 0.2.11

- 계정 메뉴의 로그인 버튼을 `로그인`으로 표시하고 아이콘을 추가함.
- 계정 메뉴 상단에 사진과 이름을 표시하고 프로필 설정을 바로 열 수 있도록 개선함.
- 사진 변경·삭제와 클라우드·동기화 옵션을 프로필 설정에 정리함.
- 앱 잠금의 PIN 입력과 버튼 배치를 다듬음.
- 기존 문서 저장 위치·앱 식별자·업데이트 서명 키와 공용 로그인 서버 연결을 유지함.

이번 릴리스는 macOS Apple Silicon용임. DMG를 열고 앱을 응용 프로그램 폴더로 끌어다 놓아 대치함. Apple 인증서 서명·공증은 적용하지 않음.
